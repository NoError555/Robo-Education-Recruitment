### 3. 如果将来需要多名教学部成员共同维护这个仓库，你认为应当如何组织文件与修改流程？
先找一个总负责人，负责开一个会议，明确所有人的分工，
之后就是在GitHub上创建Team，明确每一个团队成员的权限，身份，创建个人分支。
先明确每个人应该干什么，之后还应该明确谁来审核哪一部分的内容。
建议每位修改成员应当分多次提交修改内容，这样便于审核成员仔细审核每次的修改内容。
还要指定ddl，在ddl之后，修改人统一发起 Pull Request，确定各位成员的完成情况，之后按照分配进行审核工作，并提出修改意见。
在完成之后，在由总负责人负责合并至主仓库，之后再将内容保存到本地。
